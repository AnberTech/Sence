자주 묻는 질문

새 휴대폰으로 바꿨어요. 계정은 어떻게 복구하나요?

계정을 Apple이나 Google에 연결해 두었다면 시작 화면에서 “이미 계정이 있어요”를 누르고 같은 계정으로 로그인하세요. 연결하지 않은 경우 기존 계정은 복구할 수 없으므로, 설정 → 계정에서 미리 연결해 두는 걸 추천해요.

계정은 어떻게 삭제하나요?

설정 → 계정 → 계정 삭제에서 두 단계에 걸쳐 확인하면 돼요. 닉네임, 질문, 댓글, 팔로우는 영구 삭제되며, 투표 기록은 익명 상태로 집계에만 남아요. 사용하던 닉네임은 30일 후 다른 사람이 쓸 수 있어요.

질문이나 사용자는 어떻게 신고하나요?

카드 오른쪽 위의 “…” 메뉴를 열어 ‘질문 신고’를 선택하세요. 사용자를 신고하거나 차단하려면 해당 프로필의 “…” 메뉴를 이용하면 돼요. 댓글은 길게 눌러 신고할 수 있어요.

차단한 사람을 어떻게 해제하나요?

설정 → 차단한 계정에서 차단 해제를 누르세요. 상대를 차단해도 상대방에게는 알림이 가지 않아요.

닉네임을 바꿀 수 있나요?

네. 설정 → 내 정보 → 닉네임에서 30일에 한 번 바꿀 수 있어요.

알림이 오지 않아요.

iPhone 설정 → 알림 → Sence에서 알림이 켜져 있는지 확인해 주세요. 받고 싶은 알림 종류는 앱 내 설정 → 알림에서 고를 수 있어요.

법적 요청이나 콘텐츠 삭제 요청도 같은 이메일로 보내실 수 있어요. 해당 질문이나 프로필의 링크를 함께 보내주세요.
